## 🚨 Flagship Work

### Automated DevSecOps Pipeline
Engineered a CI pipeline that prevents insecure infrastructure from reaching deployment.

- Integrated **tfsec** to scan Terraform for misconfigurations
- Flagged public storage, open SSH exposure (0.0.0.0/0), and weak security controls
- Hardened AWS S3 with private ACLs and restricted security groups
- Enforced automated security checks via GitHub Actions on every commit

**Impact:** Established a repeatable security enforcement model that stops high-risk configurations before deployment.

## Selected Engineering Work


### Machine Learning Intrusion Detection System — NSL-KDD
Designed a machine learning–based intrusion detection pipeline to classify malicious network traffic.

- Trained a Random Forest model with GridSearchCV optimization  
- Improved rare attack detection using class-weighted training  
- Removed redundant features after importance analysis.  
- Evaluated performance with macro F1 for balanced detection  

**Performance:** 99.8% test accuracy • 0.74 macro F1  

*Note: NSL-KDD is a controlled benchmark and does not fully represent modern network traffic.*

**Next:** Building an inference API for real-time detection.
